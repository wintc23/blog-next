# 微信图文分享

公开文章、AI 动态、作品、个人动态、留言、图片工具及图片分享页输出服务端标题、摘要和绝对地址封面。图片分享页只引用公开结果，不公开原始上传图片或提示词；稳定封面入口会检查分享是否过期或撤销，不受图片临时凭据 15 分钟有效期影响。撤销后停止提供图片，但已被微信缓存或用户保存的图片无法追回。

微信内使用右上角菜单分享，需要公众号具备 JS-SDK 分享接口权限：

1. 在公众号后台的「JS 接口安全域名」配置 `wintc.top`，完成域名校验，并按后台要求配置服务器出口 IP 白名单。
2. 在 Next.js 服务的私有环境中设置 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`，重启服务。不要使用 `NEXT_PUBLIC_` 前缀，也不要提交 AppSecret。
3. 用微信打开正式域名上的页面，通过右上角菜单发送给好友、分享到朋友圈，检查标题、封面及好友分享的摘要；再站内跳转到另一篇内容并重新分享。

服务端 `/wechat/share-config` 只签名正式站点 URL。JSAPI ticket 在进程内缓存、提前两分钟刷新，同期请求合并，失败暂缓重试。当前适用于单个 Next.js 服务进程；扩容多实例或同一公众号已有其他 token 管理服务时，应先改为共用凭据与 ticket 缓存，避免重复刷新 token。

未配置公众号时不加载微信 SDK，网页仍正常提供分享元信息及系统分享文字。微信不支持以本地 IP、端口地址设置安全域名；本地页面只能验证元信息和模拟 SDK 流程。直接向聊天粘贴 URL 的展示由微信决定，不能保证自动成为图文卡片。

官方文档：https://developers.weixin.qq.com/doc/service/guide/h5/jssdk.html
