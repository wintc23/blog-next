# 网站视觉规范

适用于当前网站 blog-next 的公开页面与管理后台。常规文字最小字号为 14px，辅助信息通过颜色和间距区分，不再使用 12px。CSS、Tailwind 与 Ant Design 使用同一字号阶梯，不再为单页引入 13px、15px 等临时字号。

| 用途 | 字号 | 使用范围 |
| --- | --- | --- |
| 辅助信息 | 14px | 日期、标签、数量、次要提示；不用于主要操作 |
| 界面文字 | 14px | 按钮、链接、表单标签、简短说明、后台表格 |
| 正文 | 16px | 文章、留言、动态正文、输入内容 |
| 小标题 | 18px | 卡片标题、小节标题 |
| 区块标题 | 20px | 内容区块、移动端紧凑标题 |
| 页面标题 | 24px | 页面标题、首页栏目标题 |
| 大标题 | 32px | 首页姓名、文章主标题 |
| 展示文字 | 28 / 36 / 40 / 48px | 首屏宣传标题，按断点选用 |

正文行高 1.75，界面文字 1.5，标题 1.3–1.5；普通文字 400，标题 500–600。移动端保留正文大小，不通过缩小字来塞内容。触屏输入框至少 16px，避免 iOS 聚焦自动缩放。

颜色：灰底 #f4f4f4、白色内容面、正文 #333、说明 #666、边框 #e5e5e5。跳转链接与工具页面标题统一蓝色 #2d8cf0，悬停 #57a3f3。圆角统一 4px；头像、作品轮播圆形按钮保留原有例外。

交互使用 Ant Design。输入框聚焦只显示一层蓝色边框，不叠加外圈；键盘操作链接和按钮时保留可见焦点轮廓。手机上传固定为图标加文字，不仅靠悬浮提示。

实现：`lib/visual-tokens.ts` 为字号数值源；`app/globals.css` 提供同名 CSS 变量（rem），`tailwind.config.ts` 与 `components/Providers.tsx` 共享数值源。CSS 使用 `--font-*`，JSX 使用 Tailwind 语义字号。图标、按头像尺寸计算的首字母和新闻装饰性期号（80px）可独立缩放，不属于正文。


## 配色规范（前台与后台共用）

| 语义变量 | 值 | 用途 |
| --- | --- | --- |
| `--site-title` / `--site-text` | #333 | 普通页面、卡片、文章和后台标题；正文 |
| `--site-text-secondary` | #666 | 说明、日期、次要信息 |
| `--site-text-disabled` | #999 | 禁用状态、占位内容，不用于主要内容 |
| `--site-bg` | #f4f4f4 | 页面底色 |
| `--site-surface` | #fff | 内容面、弹窗、输入框 |
| `--site-surface-subtle` | #fafafa | 次级内容面 |
| `--site-border` | #e5e5e5 | 分割线、常规边框 |
| `--site-hover-bg` | #eee | 中性交互悬停底色 |
| `--site-primary` | #2d8cf0 | 链接、操作、选中状态、已有的蓝色栏目与工具标题 |
| `--site-primary-hover` | #57a3f3 | 蓝色交互悬停 |
| `--site-primary-active` | #1674d5 | 蓝色交互按下 |
| `--site-primary-soft` | #eaf4ff | 小范围选中状态底色，不作页面背景 |

普通标题不得使用说明灰，也不混用 #222、#555 等深浅。标题以 500–600 字重区分层级；蓝色仅作已有栏目标题及交互强调，不用低饱和灰蓝替代中性灰。

新增或修改页面必须引用 `var(--site-*)`；Tailwind 使用 `text-[var(--site-title)]` 等变量写法。不得硬编码常规文字、背景、边框、链接色，不得另建单页灰蓝色板。Ant Design 的颜色算法需要数值颜色，统一从 `lib/visual-tokens.ts` 的 `siteColors` 读取并与 CSS 变量同步。

例外仅限：作品封面与原有深色作品首屏、图片、品牌标识、代码高亮，以及成功/警告/错误状态。深色内容面使用白色标题，不能套用深灰导致不可读。审核样式时检查桌面、390px 手机屏、键盘焦点及至少一个后台表单；不因统一颜色修改内容图片。

## 导航与栏目命名

顶部统一使用「探索」，现有 `/products` 地址保持兼容；探索页按「图片工具」「个人作品」并列展示，首页使用同名栏目。工具用于直接操作，个人作品用于项目展示；生成结果归入「我的图片任务」。作品详情返回 `/products`，文案「返回个人作品」；工具详情与任务列表直接返回 `/products`，旧 `/tools` 列表地址自动跳转探索页，不保留重复的工具列表页。

普通文字链接及「全部／查看／开始使用」按钮不附加装饰性箭头。仅返回、分页、轮播、排序、折叠、回到顶部等确有方向含义的控件保留箭头。

局域网 HTTP 预览也是验证场景。前端生成 UUID 使用项目已有的 `uuid` 库，不直接依赖仅安全上下文提供的 `crypto.randomUUID()`；不要用弱随机数替代登录 state 等随机标识。

AI 行业动态公开列表：栏目标题、可点击的动态标题及日期日数字用 `--site-primary`，链接悬停用 `--site-primary-hover`；年月、阅读量和摘要用 `--site-text-secondary`。顶层列表已有主导航，不重复提供「返回首页」；详情页保留返回动态列表。

探索页入口和返回链接统一使用 `/products`，不添加定位锚点。探索页工具数据随服务端首屏渲染，避免加载完成后插入卡片引起页面位移。

侧栏仅在归档博客相关页面（`/article` 列表和详情、`/tag` 标签归档、旧 `/blog` 入口）按需加载和渲染。其他页面不挂载侧栏，不通过 CSS 隐藏占位。生活动态列表和详情使用无侧栏布局；列表不提供返回首页，按日期分组滚动加载，保留加载失败重试和加载更多入口。

## 动态与画册

动态发布沿用留言式编辑：文字输入、最多九张图片的加号上传区，支持粘贴、大图预览、拖动排序和右上角移除；日期、地点、分类收进默认折叠区，日期使用 Ant Design DatePicker。手机发布入口使用图标加文字，扫码后需在电脑核对确认码。

画册入口位于探索页，按「公开画册／我的画册」分组。新建默认私密，公开后才进入公开列表并显示分享入口；画册编辑在公开页面内完成。照片使用方形缩略图，大图保留原始比例，排序手柄兼容触摸与键盘。图片引用可复用，删除画册不删除源图片。

生活动态正文配图使用正方形格子：单图最大 240px，2／4 张使用两列，其余多图三列；整组最大 360px，窄屏随容器收缩。缩略图使用 object-fit: cover 和居中裁切铺满方格，不留白；点击查看完整、原比例大图。画册仅管理员创建和整理，其他访客只浏览公开画册，不显示创建、我的画册、加入画册和上传入口。

动态首页预览同样使用正方形、居中铺满的小图。发布动态时，有原图元数据的照片提供「小缩略图 + 时间／地点」快捷填入按钮，时间和地点独立填入，保留手动修改；不使用文件修改时间冒充拍摄时间，GPS 无地名时明确显示坐标。

动态列表的加入画册使用管理员选图模式：支持跨动态、多图选择与滚动加载，统一提交当前选择，完成后清空选择以便整理下一组。生图结果也先选图再选择画册。动态、图片工具和生图分享共用点赞控件，未登录点击时自动建立游客身份，不弹出正式登录窗口。

生活动态的公开页面只显示日期，不显示时分；拍摄时间保留用于编辑和排序。首页最多展示最近两条动态，正文最多两行、预览图片最大 72px 正方形，日期与点赞同一行，完整内容通过动态详情或全部动态查看，不使用固定高度裁掉操作入口。

选图加入画册的操作区放在内容顶部右侧，随页面正常滚动，不固定悬浮。点赞使用空心红心／实心红心区分未点赞和已点赞，默认、悬停与已点赞颜色使用 `--site-like`、`--site-like-hover`，默认、悬停、按下和已点赞状态均不显示背景，显式覆盖 Ant Design 默认文本按钮样式。首页动态左下角的日期和地点同行，以空格间距分隔，地点过长省略，点赞位于右侧。

动态图片的选图复选框不添加外层白色底块，保留 Ant Design 复选框本身的选中、悬停与焦点状态。生图结果的分享入口、选图分享弹窗和取消分享操作仅管理员可用；普通用户可继续查看、生成和下载自己的图片。后端同步检查分享权限及分享所有者当前的管理员权限。

管理员可从动态列表和详情页的「编辑」直接进入对应动态编辑框。生图管理的「全站任务」支持分页查看所有已提交任务，详情包含所属账号、原图／结果图大图预览、用户提示词、创建时的完整配置及执行状态；普通账号不可访问管理接口。

动态图片右下角使用眼睛／隐藏图标切换站内访客可见性，默认公开。管理员可在列表、详情和编辑框操作；首页、列表、详情、分享元数据及旧个人资料接口由后端过滤隐藏图片，兼容封面字段不得泄漏隐藏图。隐藏控制站内展示，不撤回已被保存的公开云图片地址。

动态与画册中的逐图可见性独立；从动态新加入画册时继承当时的状态，之后互不联动，重复添加不覆盖画册已有设置。同图加入多本画册时各自设置；私密画册仍由画册权限控制，图片标为公开不会公开整本画册。

图片按住 200ms 后开始拖动，浮层跟随鼠标／手指，周围图片以 transform 过渡让位，松手后落位。短按保留大图预览；键盘空格开始／确认排序、方向键移动、Escape 取消；减少动态效果偏好禁用落位动画。删除叉号视觉为 18px，小于点击区域，触屏保持 44px 点击区。图片操作按钮共用 CSS 变量和 Ant Design。

加入画册弹窗默认平铺所有画册，按标签方式多选，最后一项为「＋新建画册」。新建完成自动选中且保留此前的图片和画册选择。
